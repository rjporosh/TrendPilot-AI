# TrendPilot AI — Release Notes

## Version 0.1.0 — Initial Specification

### Planned

* Python-first application architecture.
* AI provider abstraction.
* Bengali script and narration pipeline.
* AI-generated visuals and FFmpeg rendering.
* Rights and quality checks.
* Official YouTube and Meta publishing adapters.
* Scheduler, analytics and cost tracking.
* Responsive dashboard and mock mode.

### Pending Verification

* Actual AI/token provider and API access.
* Visual-generation and Bengali TTS providers.
* YouTube upload authorization.
* Meta app permissions and account eligibility.
* Live publishing and analytics tests.
* Monetization eligibility.

### Release Policy

A feature is not considered complete merely because its interface exists. Live API features must be tested with authorized accounts. Mocked or unverified functionality must be labelled clearly.
